inciSight – AI Beauty Product Scanner

A full stack web application that helps users scan beauty and skincare products, analyze ingredients, and receive AI-assisted safety insights through a structured and scalable workflow.

  • Built a full stack application using Next.js, TypeScript, Tailwind CSS, Prisma, PostgreSQL, and Vercel, connecting the frontend, backend, database, and deployment layers into one product workflow.
  • Implemented core features including ingredient analysis, risk scoring, product comparison, and AI-generated explanations to turn raw ingredient data into useful, user-facing insights.
  • Designed the app around connected workflows such as image upload, structured data handling, live interface feedback, and future OCR/recommendation support to create a scalable foundation for growth.

Tech Stack: Next.js, TypeScript, Tailwind CSS, Prisma, PostgreSQL, OpenAI API, Vercel
